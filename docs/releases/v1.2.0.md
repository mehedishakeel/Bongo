# Bongo v1.2.0 — Borno Layout, Windows Tray & System Startup

We are thrilled to announce **Bongo v1.2.0**, a major feature release introducing the **Borno (SafeWorks)** keyboard layout across all operating systems, a native **Windows System Tray** integration with dynamic mode badges and customizable shortcuts, cross-platform **System Startup** autostart management, official **Arch Linux AUR** packaging, a standalone **AppImage** for immutable distributions (SteamOS, Bazzite, Fedora Silverblue), and substantial typing responsiveness improvements on Android!

---

## 🌟 What's New in v1.2.0

### 🇧🇩 Borno (SafeWorks) Keyboard Layout Support
- **Full Standard Coverage**: Implemented full support for the Borno (SafeWorks) keyboard layout scheme across the unified core engine.
- **Embedded Engine Integration**: Layout rules, vowels, consonants, and conjunct mapping tables are compiled into the core engine runtime, guaranteeing zero-latency offline transliteration.
- **Multi-Layout Switching**: Seamlessly toggle between **Avro Phonetic**, **National (Bijoy)**, and **Borno** in Settings across macOS, Windows, Linux, and Android.
- **Interactive Cheatsheet**: Updated the layout viewer with instant visual keymaps and typing guides for all three supported layouts.

### 🪟 Windows System Tray & Dynamic Shortcuts
- **Native System Tray Integration**: Added Win32 notification area icon (`Shell_NotifyIconW`) with live GDI badge indicators (`[EN]` / `[বা]`), single-click mode toggling, double-click for settings, and a right-click context menu (Settings, About, Exit).
- **Customizable Global Shortcuts**: Choose your preferred toggle hotkey in Settings (**`Win+Space`**, **`Ctrl+Shift`**, **`Ctrl+Space`**, or **`F12`**) with instantaneous live reload—no background service restart required.
- **Safe Startup Mode**: Background service now starts in **English** by default, preventing accidental Bengali typing when entering passwords or command prompts at system login.

### 🚀 Cross-Platform System Startup Management
- **Universal Settings Card**: Added a dedicated **"System Startup"** section with a visual "Enabled" checkbox in the Settings UI on macOS, Windows, and Linux.
  - **macOS**: Uses modern `ServiceManagement` (`SMAppService.mainApp`) for background launch at login.
  - **Windows**: Manages `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
  - **Linux**: Manages standard XDG desktop autostart (`~/.config/autostart/app.getbongo.Bongo.desktop`).

### 🐧 Linux Packaging Expansion & Immutable Distros
- **Arch Linux (AUR)**: Published official `bongo-bin` package files (`PKGBUILD`, `.SRCINFO`, `bongo-bin.install`) for Arch Linux, Manjaro, EndeavourOS, and Omarchy. Install easily via `yay -S bongo-bin`.
- **Standalone AppImage**: Added standalone AppImage packages (`Bongo-1.2.0-linux-x86_64.AppImage` and `aarch64`) tailored for immutable operating systems (SteamOS on Steam Deck, Bazzite, Fedora Silverblue) with a rootless `--install-user` mode.
- **Fcitx5 Stability**: Fixed key consumption issues when there is no visible composition (PR #15).

### 📱 Android Performance & Experience Overhaul
- **Zero-Latency Touch Dispatch**: Eliminated typing lag with optimized instant touch dispatch and key view recycling, delivering a fluid, responsive typing experience on smartphones and tablets.
- **Multi-Layout Mobile UI**: Switch on-the-fly between Avro, Bijoy, and Borno directly on mobile.

## ⚡ Quick Install Commands

### Arch Linux (AUR)
```bash
yay -S bongo-bin
```

### Linux Immutable Distros (SteamOS / Bazzite / Silverblue)
```bash
chmod +x Bongo-1.2.0-linux-x86_64.AppImage
./Bongo-1.2.0-linux-x86_64.AppImage --install-user
```

### Linux Universal One-Liner
```bash
curl -sSL https://getbongo.app/install.sh | bash
```

### macOS via Homebrew Cask
```bash
brew tap mehedishakeel/bongo https://github.com/mehedishakeel/Bongo
brew install --cask bongo
```
