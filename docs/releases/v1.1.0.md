# Bongo v1.1.0 — National (Bijoy) Layout & Native Fcitx5 Frontend

We are thrilled to announce **Bongo v1.1.0**, a major release introducing the **National (Bijoy BDS 1738:2004)** layout alongside **Avro Phonetic**, a native **Fcitx5** frontend for modern Linux desktop environments, universal prebuilt Linux tarballs, an interactive dual-layout cheatsheet in Settings, and updated packages for macOS, Linux, Windows, and Android!

---

## 🌟 What's New in v1.1.0

### 🇧🇩 National / Bijoy BDS 1738:2004 Layout Support
- **Full Standard Coverage**: Implemented complete support for the National (Bijoy BDS 1738:2004 compatible) keyboard layout across the unified core engine.
- **Embedded Engine Integration**: Layout rules and conjunct mapping tables are directly embedded within the Rust core engine runtime (`riti`), guaranteeing offline, zero-latency transliteration across all supported operating systems.
- **Seamless Layout Switching**: Effortlessly toggle between Avro Phonetic and National (Bijoy) layout with zero restarts or re-configurations.
- **Comprehensive Test Suite**: Verified against 100+ Bengali conjuncts (যুক্তবর্ণ), vowels, kar diacritics, ref, hasant, and numeral conversions.

### 🐧 Native Fcitx5 Frontend & Universal Linux Tarballs
- **Modern Desktop IME**: Added a native C++ Fcitx5 addon alongside our existing IBus engine, bringing first-class Bengali input to modern Wayland compositors (KDE Plasma 6, GNOME Wayland, Hyprland, Sway) as well as X11.
- **Universal Prebuilt Tarballs**: Added standalone, distribution-independent prebuilt tarballs (`Bongo-1.1.0-linux-x86_64.tar.gz` and `Bongo-1.1.0-linux-aarch64.tar.gz`) for Fedora, Arch Linux, openSUSE, and other non-Debian distributions without needing a local Rust/C++ compiler.
- **Floating Candidate HUD**: Real-time preedit styling, responsive suggestion window, and single-keypress numeric shortcuts (1–9).
- **GUI Settings Integration**: Full configuration support through `fcitx5-configtool` for typing modes and emoji suggestions.
- **Smart Installer & Clean Uninstall**: The one-command installer script (`platforms/linux/scripts/install.sh`) automatically detects your running desktop environment, configures the appropriate input framework, and provides a scoped `--uninstall` mechanism.

### 🎨 Interactive Dual-Layout Cheatsheet
- **Interactive UI**: Redesigned the visual layout cheatsheet in Settings on macOS, Linux, and Windows to include an instant layout switcher tab (Avro Phonetic vs National / Bijoy).
- **Proportional Key Grid**: Balanced key chip dimensions and grid columns (`j`, `J`, `t`, `T`) with a dedicated typographic rules card.

### 📱 Android Mobile IME
- **Bongo for Android v1.1.0**: Built with SDK 34 and Material Design 3.
- **Dual-Engine Architecture**: Native JNI bindings with robust pure-Kotlin fallback transliterator.
- **Sideload Ready**: Pre-signed APK ready to install directly on smartphones and tablets without requiring Google Play.

### 🪟 Windows Suite
- **Multiple Distribution Formats**: Available as an Inno Setup installer (`.exe`), enterprise-ready WiX Toolset MSI (`.msi`), and a zero-install portable archive (`.zip`).
- **Startup & Theme Fixes**: Resolved settings launcher initialization exception (`ACCENT` color token) and validated full UI lifecycle.
- **Complete Test Matrix**: 100% CI test pass rate across engine, background service, and settings UI.

## ⚡ Quick Install Commands

### Linux One-Liner (Auto-installs & Configures)
```bash
curl -fsSL https://getbongo.app/install.sh | bash
```

### Linux Universal Prebuilt Tarball
```bash
tar -xzf Bongo-1.1.0-linux-x86_64.tar.gz
cd Bongo-1.1.0-linux-x86_64
sudo bash install.sh --prebuilt
```

### macOS Homebrew Cask
```bash
brew install --cask mehedishakeel/bongo/bongo
```
