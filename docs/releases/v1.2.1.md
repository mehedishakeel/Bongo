# Bongo v1.2.1 — Linguistic Converters, User Dictionary & Engine Parity

We are excited to release **Bongo v1.2.1**, bringing feature parity, linguistic converters, and phonetic intelligence across all supported operating systems (Windows, macOS, Linux, and Android).

---

## 🌟 What's New in v1.2.1

### ⇄ Desktop Tools & Converters Tab (macOS, Windows, Linux)
- **Bijoy (ANSI) ⇄ Unicode Text Converter**: High-performance bidirectional converter between classic Bijoy (SutonnyMJ) and modern Unicode text. Features one-click action buttons, instant clipboard copy, and batch conversion for documents and publishing.
- **Bengali Number-to-Words Converter**: Decomposes numbers (in English `0-9` or Bengali `০-৯` digits) into spoken Bengali words (`কোটি`, `লক্ষ`, `হাজার`, `শত`, `একক/দশক`). Includes an optional currency mode for Taka (`টাকা মাত্র`).
- **Unified Settings Navigation**: Clean 6-tab navigation layout across macOS (`ConvertersView`), Windows, and Linux (`create_converters_view`).
- **Core CLI Engine**: Standalone CLI execution via `platforms/common/converter.py` (`python3 converter.py u2b / b2u / num`).

### 📱 Android Keyboard Enhancements & Complete Parity
- **Custom Shortcuts & User Dictionary Manager (⚡)**: Full dictionary manager in Android settings supporting custom abbreviations, starter presets (`fb`, `bd`, `dhaka`, `thx`, `gm`, `gn`, `yt`), and JSON export/import. Custom shortcuts receive top priority badges in suggestions.
- **Multi-Item Clipboard History Drawer**: Accessible from the keyboard toolbar with quick-paste chips for up to 10 recent clips and a one-tap dismiss button.
- **Punctuation Direct-Commit Fix**: Separated `/` and `,` click handling, and enabled direct commit for `/` and `\` so they are never trapped in phonetic pre-edit buffers.
- **Interactive Bengali Number Converter**: Live converter in Android Settings with one-tap copy.

### 🧠 Phonetic Engine & Autocorrect Expansion
- **Fuzzy Chandrabindu (`^`) Auto-Suggestions**: Expanded autocorrect rules across all platforms for words frequently typed without explicit `^` input (`baka` ➔ `বাঁকা`, `khocha` ➔ `খোঁচা`, `radha` ➔ `রাঁধা`, `tak` ➔ `টাঁক`, `chuch` ➔ `ছুঁচ`, `jak` ➔ `ঝাঁক`).
- **Expanded Loanwords**: Added shortcuts for `bd` (বাংলাদেশ), `dhaka` (ঢাকা), and `thx` (ধন্যবাদ).
