# Bongo v1.2.2 — Glide Typing, Structured Clipboard, Incognito & Cross-Platform Parity

Bongo v1.2.2 introduces major typing, privacy, security, and cross-platform candidate/theme parity improvements across Android, macOS, Linux, and Windows.

## Highlights

- **Android Security & Privacy Hardening**:
  - Disabled cloud/USB device backup (`android:allowBackup="false"`) for local preferences, learned words, and clipboard history.
  - Enforced **Incognito Mode** (`IME_FLAG_NO_PERSONALIZED_LEARNING`, password fields, and manual Options toggle), suppressing personalized learning, typing stats, and clipboard recording.
  - Added Android 13+ `ClipDescription.EXTRA_IS_SENSITIVE` checks plus automatic 1-hour expiration on sensitive clipboard items.
- **Structured Clipboard Manager & Search**:
  - Dedicated in-keyboard Clipboard view supporting item pinning, single-item delete, clear unpinned, search filtering (`ক্লিপবোর্ড খুঁজুন`), and quick paste.
- **Smart Typing & Productivity (Android)**:
  - **Glide Typing (Swipe-to-Type)** with finger trail overlay and Bengali/English vocabulary matching (`glideTyping` preference toggle).
  - **Double-tap Shift Caps Lock** and **English Auto-Capitalization** (`autoCapitalization` preference toggle).
  - **Dev / Programmer Symbol Layer** inside the options panel (`->`, `!=`, `>=`, `<=`, `===`, `() =>`, brackets, and operators).
  - **Inline Quick Math (`=`)**: Type an expression such as `25*4=` or `১২+৩=` to get a one-tap result candidate.
  - **Undo Swipe-Delete** banner action (`↩ Undo`) and working **Spacebar Cursor Scrubbing** toggle (`cursorScrubbing`).
  - **Bilingual Emoji Search** and **Tablet / Landscape layout optimizations**.
- **Cross-Platform Parity**:
  - Configurable candidate suggestion count (3–9) across macOS, Linux (IBus & Fcitx5), Windows, and Android.
  - Light/Dark/System appearance support on macOS and Windows UI, plus Borno layout parity and expanded contextual bigrams across all platforms.
- **Testing & CI**:
  - Added pure-JVM JUnit test suite (`AvroPhoneticEngineTest`, `BijoyConverterTest`, `BengaliNumberToWordsTest`, `MathEvaluatorTest`, `ClipboardModelTest`).
  - Fixed release workflow keystore decoding and added Android unit test gating before APK assembly.
