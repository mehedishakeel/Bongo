# Bongo v1.2.3 — Spacebar Multi-Layout Switching (Bongo, National, Borno, English)

Bongo v1.2.3 restores direct Spacebar swipe input-mode switching on Android and brings all input layouts onto the Spacebar wheel.

## Highlights

- **Spacebar Swipe Restored**: Restored Spacebar horizontal swipe to switch input modes by default (moving Spacebar trackpad cursor scrubbing to opt-in in Settings, while keeping `◀` / `▶` cursor buttons on the top strip).
- **Removed Strip Language Toggle**: Reverted the temporary `🌐` language pill from the candidate/shortcut strip to restore a clean shortcut bar.
- **All Input Layouts on Spacebar**: Swiping the Spacebar cycles across all four input layouts in both directions: **English ↔ Bongo ↔ National ↔ Borno ↔ English**.
- **Native National & Borno Support on Android**: Added pure-Kotlin `FixedLayoutEngine` implementing `National` (`National.json`) and `Borno` (`Borno.json`) keymaps with live Bengali keycaps and pre-base kar reordering.
