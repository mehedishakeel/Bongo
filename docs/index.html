Get started

Install Bongo on your computer.

Download the matching release asset, then follow the short platform guide.

01

Download

Get the latest Apple Silicon DMG from GitHub Releases.

02

Install

Open the DMG, drag Bongo to Applications, then launch Bongo and install its input method.

03

Enable

Log out and back in once. Add Bongo under Keyboard → Input Sources, then switch with Control–Space.

01

Download

Get the DEB matching your architecture from GitHub Releases.

02

Install

Run sudo apt install ./Bongo_1.0-ARCH.deb from the download folder.

03

Enable

Log out and back in, then add Bongo from your desktop environment’s input source settings.

Questions

Good to know.

Does Bongo need an internet connection?

No. Bangla conversion runs locally. Internet access is used only when you ask Bongo to check GitHub for a newer release.

Where can I report a problem?

Open an issue in the Bongo GitHub repository with your platform and steps to reproduce it.

Is Bongo open source?

Yes. Source code, license information, and upstream project acknowledgements are available in the GitHub repository.
